# MdSvelte

A markdown parser that renders into Svelte components. Inspired by [svelte-markdown](https://www.npmjs.com/package/svelte-markdown), but uses [remark-parse](https://www.npmjs.com/package/remark-parse) under the hood instead of marked.

# Installation

```sh
npm i @jazzymcjazz/mdsvelte
```

# Requirements

As of version 0.3.0 Svelte 5 is required.

# Usage

### Basic

```html
<script>
	import { MdSvelte } from '@jazzymcjazz/mdsvelte';

	const source = `
# Some Header

Some paragraph

- List item
- List item with nested list items
  1. Item
  2. Item with even deeper nested list items
    - Item 1
    - Item 2

| Table Header 1 | Table Header 2 |
|----------------|----------------|
| Some | data |`;
</script>

<MdSvelte {source} />
```

### Custom Renderer

```html
<script>
    import { MdSvelte } from '@jazzymcjazz/mdsvelte';
    import MyCustomCodeComponent from '$libMyCustomCodeComponent';

    const source = '...';
</script>

<MdSvelte
    {source}
    renderers={{
        code: MyCustomCodeComponent
    }}
/>
```

### Onparse Callback

If you need access to the AST generated by `Remark`, you can use the `onparse` function prop, which is called after the markdown source has been parsed into an AST.

```html
<script>
    import { MdSvelte, type Root } from '@jazzymcjazz/mdsvelte';

    const source = '...';

    function onparse(node: Root) {
        console.log(node);
    }

</script>

<MdSvelte {source} {onparse} />
```

### Extensions

You can use any plugins that work with unified. Note that additional plugins are installed between `remark-rehype` and `rehype-stringify`;

```js
const processor = unified()
	.use(remarkParse)
	.use(remarkRehype)
	// Added plugins here
	.use(rehypeStringify);
```

To add plugins use `MdProcessor`. Note that MdSvelte currently only supports global plugins. This means that all instances of `MdSvelte` will use the same plugins. Calling `MdProcessor.setGlobalPlugins` will overwrite any previously set plugins.

In a future release, it will be possible to set plugins on a per-instance basis.

```html
<script>
	import { MdSvelte, MdProcessor } from '@jazzymcjazz/mdsvelte';
	import rehypeHighlight from 'rehype-highlight';
	import remarkGfm from 'remark-gfm';

	MdProcessor.setGlobalPlugins({
        remarkPlugins: [remarkGfm],
        rehypePlugins: [rehypeHighlight]
        remarkRehypeOptions: {}
    });

	const source = '...';
</script>

<MdSvelte {source} />
```
